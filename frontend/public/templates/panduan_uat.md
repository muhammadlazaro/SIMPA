# Panduan singkat UAT

1. Unduh template UAT.
2. Sesuaikan skenario uji dengan proses bisnis unit kerja.
3. Jalankan uji pada aplikasi versi yang akan dirilis.
4. Tandai setiap skenario: Lulus atau Gagal.
5. Beri catatan rinci untuk skenario gagal.
6. Simpan hasil dalam PDF/DOC/DOCX.
7. Unggah kembali melalui menu Dokumen Unit Kerja.

## Tips

- Gunakan bahasa yang jelas pada langkah uji.
- Lampirkan bukti (screenshot) di dalam dokumen jika perlu.
- Pastikan nama file memuat nama aplikasi dan tanggal.
